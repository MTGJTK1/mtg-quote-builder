# MT Group Quote Builder

## Read these first

- `docs/MTG_Quote_Builder_Spec.md` — the field-by-field behavior spec.
- `docs/MTG_Quote_Builder_Build_Brief.md` — stack, schema, folder layout,
  phased build order.

Both are the source of truth. When the spec and an assumption disagree, the
spec wins.

## Things that will bite you

- **Spec §4 lists approaches that were built and deliberately reverted**
  (structured timepoint anchor/offset, subcohort tumor-type tagging, shipping
  markup multiplier, numeric timeline fields, a live summary preview in
  Timeline). Don't rebuild any of them without a new reason — they were removed
  because they didn't match how reps actually work, not because they were
  unfinished.
- **Section numbering is load-bearing.** Pricing blocks in §10 are numbered to
  match the specimen order in §05, and validation messages in §11 refer to
  sections by number.
- **Document formatting is verified by comparison, not inspection.** Render
  output to PDF and compare page-by-page against a real quote before calling
  any formatting work done — see `lib/docx/README.md`.
- **Money is `Decimal`, never a JS float.** Prisma returns its own `Decimal`
  type for `totalCost` and `price`; keep pricing math off `number`.
- **Pricing notes in §10 are internal-only.** They must never reach the
  sponsor-facing document.

## Conventions

- Prisma client is a singleton from `@/lib/db`; never construct `PrismaClient`
  directly. Prisma 7 requires a driver adapter (`@prisma/adapter-pg`).
- The generated Prisma client (`lib/generated/prisma`) is gitignored and
  regenerated by `postinstall`.
- Two database URLs, not one: `DATABASE_URL` (pooled) for the app,
  `DIRECT_URL` (unpooled) for migrations — `prisma7.config.ts` prefers the
  latter. Pointing migrations at a transaction-mode pooler fails on lock
  acquisition, sometimes only under load.
- Route handler dynamic params are promises: `await ctx.params`.
- A server component cannot call a function exported from a `'use client'`
  module. Shared helpers the pages need (`emptyQuote`, form value types) live in
  `lib/quoteFormValues.ts`, not in the form component. This fails only at
  runtime — lint, typecheck and build all pass — so exercise pages in a browser.
- Every form control gets a label tied to it by id; `components/quotes/QuoteForm.tsx`
  has a `Field` wrapper that does this. Sibling label/input markup leaves the
  input unlabelled for screen readers.
- Folders prefixed with `_` are private and excluded from routing.
- Prisma versions are pinned exactly — npm's `latest` tag for `prisma`
  currently points at an 8.0.0 release candidate, so don't run a bare
  `npm install prisma`.
