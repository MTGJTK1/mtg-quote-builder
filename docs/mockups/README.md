# Clickable mockups

Standalone HTML files that mirror a build phase closely enough to gather
feedback on layout and wording before the real screens are finished. Open one
directly in a browser — no server, no database, no build step.

They save to browser local storage only. Nothing here touches the real
application or its data.

| File | Mirrors | Notes |
|---|---|---|
| `phase-2-clickable-mockup.html` | The full eleven-section intake, plus the register | Seeds eight sample quotes; "Reset sample data" restores them. Population groups and subpopulations are the live HubSpot enum values read from portal 7423331 on 2026-08-27. |

Keep a mockup in sync with the phase it mirrors, or delete it once the real
screens are live — a stale mockup collects feedback on a design nobody is
building any more.
